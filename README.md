# Sju sorters kakor

En enkel receptwebbplats med sju klassiska svenska kakrecept.

## Filer
- `index.html` – sidans innehåll och struktur.
- `style.css` – sidans separata stilmall.

## Bilder som behöver läggas till
HTML-filen refererar till följande bildfiler. Lägg dem i samma mapp som `index.html` för att bilderna ska visas:

- `cookie-pattern-background.png`
- `cookie-photo.jpg`
- `drommar-photo.jpg`
- `finska-pinnar-photo.jpg`
- `finska-pinnar-ingredients.jpg`
- `hallongrottor-photo.jpg`
- `kolasnittar-photo.jpg`
- `schackrutor-photo.jpg`
- `schackrutor-ingredients.jpg`
- `sockerkringlor-photo.jpg`
- `kokostoppar-photo.jpg`

## Publicera med GitHub Pages
1. Skapa ett nytt repository på GitHub.
2. Ladda upp `index.html`, `style.css` och bildfilerna ovan.
3. Öppna repositoryts **Settings → Pages**.
4. Under **Build and deployment**, välj **Deploy from a branch**, välj `main` och `/ (root)`, och spara.
5. När publiceringen är klar visas webbplatsens adress på samma Pages-sida.
